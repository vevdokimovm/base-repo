# tests/ — регрессионный набор инфраструктуры

Тесты на то, что ломается молча и дорого. Сейчас закрыт `templates/deploy.sh` —
единственный деплойер системы.

## Запуск

```bash
bash tests/test_deploy.sh        # из корня base-repo
```

Ноль зависимостей: ни сети, ни GitHub-токена, ни реальных реп.
Вместо GitHub — локальные bare-репы (`REMOTE_BASE`), вместо `gh` — стаб `tests/bin/gh`
с журналом вызовов. Код возврата `0` — зелено, `1` — есть падения.

## Что покрыто (15 кейсов, 54 проверки)

| # | Кейс | Зачем |
|---|---|---|
| 1 | Новая репа: создание → коммит → тег → релиз → ассет | базовый цикл целиком |
| 2 | Серия версий: каждый тег на СВОЁМ дереве | регресс PIT-014 (stat-кэш git) |
| 3 | Идемпотентность | повторный прогон безопасен |
| 4 | Нейминг: подчёркивания принимаются, помечаются | `43` — легаси не ломаем |
| 5 | `__MACOSX`/`.DS_Store` не ломают пуш | регресс PIT-015 |
| 6 | Хвост ` copy` / `(1)` в имени | реальные файлы из Downloads |
| 7 | Битый архив без README | репа НЕ разрушена |
| 8 | `VERSION` ≠ версии в имени | стоп по версии |
| 9 | `DRY=1` | ни одного изменения |
| 10 | Заглушка чинится, осмысленное описание — нет | `21-revision-protocol` |
| 11 | CHANGELOG без тезиса | предупреждение, публикация идёт |
| 12 | Тег на чужом дереве → fail loud | не чиним молча |
| 13 | `ONLY` / `SKIP` | фильтры |
| 14 | repos-map: авто-регистрация новой репы | без дублей |
| 15 | Правка карты не теряется во временном клоне | регресс боевого прогона |

## Правило

Поймал баг в деплойере — **сначала тест, который его воспроизводит**, потом фикс.
Кейсы 2, 5, 15 появились именно так: это пойманные баги, а не гипотезы.
