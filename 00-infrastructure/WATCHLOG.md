## §2. Направление репы

  как template для новых реп.
- **Что НЕ входит в репу:** тематический контент (он в тематических репах). Здесь —
  только инфраструктура и правила.

## §4. Находки и грабли (не переоткрывать)

- **2026-07-05** — GitHub template **не синхронизируется** с потомками (в отличие от
  fork). Template = фабрика скелетов на момент создания, а не живое наследование.
  Разобрано в `09-template-repository.md`.
- **2026-07-05** — тяжёлые файлы остаются в истории git навсегда и качаются при каждом
  клоне, даже после удаления. Дельта-сжатие не берёт JPEG/MP4/ZIP/docx. Отсюда — не
  пускать тяжёлое в историю вообще. Разобрано в `10-git-reference.md` §2.
- **2026-07-08** — при работе с нескольких аккаунтов параллельные ветки документации
  дают **одинаковые номера разным докам** (при слиянии v1.2.0 встретились три разных
  «09/10»). Сверять по **содержимому**, не по имени/номеру/дате файла: копия кита может
  быть собрана с более раннего снапшота, чем актуальная репа (так было с 01/05/06 —
  в ките не хватало порогов размера v1.1.0). Новым докам номер присваивается в момент
  слияния в base-repo.
- **2026-07-08** — macOS-zip отдаёт имена в NFD («й» = «и»+диакритика) — пути с кириллицей
  могут «не находиться» при точном совпадении строки. Лечится нормализацией в NFC
  (`unicodedata.normalize('NFC', name)`). Плюс мусор `__MACOSX/` и `.DS_Store` — чистить
  до коммита (корневой `.gitignore` уже прикрывает `.DS_Store`).
