# 08 — Автоматические триггеры и советы

> Таблица «событие → действие»: как только случается левое, делаешь правое. Чтобы
> поддержание репы шло на автопилоте, а не «когда-нибудь разгребу». Многие триггеры
> может отрабатывать Claude сам, если попросить или держать этот файл в knowledge проекта.

## Триггеры

| Событие | Действие | Правило |
|---|---|---|
| Загрузил большой/сырой файл (`.docx`, `.pdf`, длинный) | Сжать в тезисный `.md`, оригинал — локально или в `sources/` | `06` |
| Заметил два материала про одно | Слить в один, лишнее удалить | `05` пр. 2 |
| Тема разрослась внутри папки | Выделить в отдельную папку с префиксом | `05` цикл |
| Тема доросла до самостоятельной области | Вынести в отдельную репу | `05` цикл |
| Попался файл не по теме репы | В свою репу или `misc-vault`, не сюда | `01` §2.5 |
| Начал сессию/принял вахту | Прочитать `WATCHLOG.md` §0/§2/§4 | `04` §4 |
| Закончил подшаг | Обновить §0 журнала | `04` §3 |
| Внёс значимое изменение | Добавить строку в §3 журнала (окно N) | `04` §3 |
| Нашёл грабли/важный факт | Записать в §4 журнала | `04` §3 |
| Материал устарел | Обновить или удалить | `05` пр. 1 |
| Репа стала тяжёлой, Claude «теряет» части | Ревизия: сжать тяжёлое, вычистить дубли и генерируемое | `02`, `05`, `06` |
| Сделал заметный кусок ревизии | Закоммитить сразу, не копить до конца | `04` §5 |
| Вопрос о ценах/лимитах Claude | Смотреть по докам, не по памяти | `02` §5 |
| Задача крупная/спорная | Взять Opus · high вместо дефолтного Sonnet | `02` §3 |

## Периодическая ревизия (раз в период)

Прогони репу по чек-листу правил чистоты (`05`):
1. Актуальность — есть устаревшее? Обнови/удали.
2. Дубли — есть повторы? Слей.
3. Обобщённость — есть сырой копипаст вместо тезисов? Сожми.
4. Лёгкость — есть тяжёлое/генерируемое? Вынеси/удали.
5. Чистота зоны — есть чужое? Перенеси.

Удобно делать в Cowork: даёшь репу + правила `05`/`06`, просишь пройтись и предложить
правки. Claude находит дубли/тяжёлое, ты подтверждаешь — и коммитишь частями.

## Совет по ритму

Не «однажды наведу порядок», а **маленькими шагами по триггеру**. Каждый заход
оставляет репу чуть чище, чем была. Журнал (`04`) держит преемственность между заходами.
