# CHANGELOG — история инфраструктуры

> История версий правил и стандартов `base-repo`. Раз это источник правды для всех
> реп, изменения правил трекаются здесь — чтобы было видно что и когда поменялось,
> и чтобы тематические репы могли свериться с актуальной версией.
>
> Формат: обратный хронологический (новое сверху). Версии — semver-подобно:
> MAJOR — несовместимое изменение правил (меняет структуру существующих реп),
> MINOR — новое правило/документ без слома старого, PATCH — уточнение/правка.

## [1.1.0] — 2026-07-05

### Added
- `09-template-repository.md` — как использовать base-repo как GitHub template для
  заведения новых реп; разбор template vs fork vs clone; подводный камень отсутствия
  синхронизации.
- `10-git-reference.md` — полный справочник по Git: модель хранения (blob/tree/commit),
  ключевое ограничение (история хранит всё навсегда), лимиты GitHub (файл/репа/рендер),
  рабочие команды, восстановление, обнуление истории, `.gitignore`, связка Git + Claude.
- `README.md` (корневой) — лицо репы: концепция базового класса, навигация, как пользоваться.
- `WATCHLOG.md` — живой вахтенный журнал base-repo.
- `CHANGELOG.md` — этот файл.

### Changed
- `01-repo-standard.md` §4 — добавлены пороги размера репы: 🟢 ≤50 МБ (норма),
  🟡 100 МБ (мягкий потолок), 🔴 500 МБ (жёсткий, завязан на лимит контекста Claude).
- `06-volume-compression.md` — добавлены жёсткие правила по типам файлов (docx/pptx/zip
  не в репе; PDF ≤5 МБ; картинки ≤0.5 МБ и только по делу; TIFF→PNG), раздел с фактами
  о лимитах GitHub, раздел о порогах размера.
- `05-knowledge-base-rules.md` — правило «Лёгкость» усилено конкретными числами и
  запретом на архивные форматы.
- `repos-map.md` — перенесён в base-repo (его законное место); добавлена запись про
  `base-repo` как родителя системы.
- `START-HERE.md`, `00-infrastructure/README.md` — переработаны под концепцию base-repo
  как родительской репы (было: «кит, копируемый в каждую репу»).
