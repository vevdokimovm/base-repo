# CHANGELOG — история инфраструктуры

> История версий правил и стандартов `base-repo`. Раз это источник правды для всех
> реп, изменения правил трекаются здесь — чтобы было видно что и когда поменялось,
> и чтобы тематические репы могли свериться с актуальной версией.
>
> Формат: обратный хронологический (новое сверху). Версии — semver-подобно:
> MAJOR — несовместимое изменение правил (меняет структуру существующих реп),
> MINOR — новое правило/документ без слома старого, PATCH — уточнение/правка.

## [1.7.0] — 2026-07-09 — Универсальный деплойер: любая репа из архива одной командой

Ответ на вопрос владельца «почему деплой версионный?»: универсальное ядро (publish.sh) было,
не хватало универсальной внешней обвязки «zip → push» как у FINPILOT-публикатора. Теперь она —
канон в репе; версионные одноразовые обёртки больше не нужны.

### Added
- **`templates/deploy_from_zip.sh`** — универсальный деплой любой репы системы из архива:
  `zsh deploy_from_zip.sh <repo>-vX_Y_Z.zip` → sha256-сверка (`SHA=`), разворот обёртки
  (PIT-007), **маркеры корня перед деструктивом**, клон, чистая замена дерева кроме `.git`
  (PIT-004), `add -A -f` (PIT-006), push с ретраями, автопроверка **«файлов в коммите ==
  файлов в дереве»** (строгое равенство вместо «больше нуля»), затем сам вызывает
  `publish.sh --version <V> --auto-asset` из дерева. Имя репы и версия выводятся из обёртки
  `<repo>-vX_Y_Z/` и/или файла `VERSION` (оба есть → обязаны совпадать, иначе стоп; ни одного →
  только push с предупреждением). `ALSO_PUBLISH="X.Y.Z ..."` — доделка старых релизов
  (заглушечные описания, недостающие ассеты) тем же прогоном. Пара к publish.sh: тот работает
  внутри клона, деплойер — снаружи. Вписан в `25` §3, триггер в `08`, карта README,
  START-HERE шаг 6.

### Changed
- **`00-infrastructure/push_base_repo.sh`** — помечен суперсиженным (`[СУПЕРСИД v1.7.0]` в
  шапке, преемник — `templates/deploy_from_zip.sh`); оставлен как base-repo-специфичный
  шорткат. Протухший дефолт `MSG` (зашитый текст v1.5.0) заменён нейтральным
  `release: base-repo tree sync`.

### Notes
- **v1.6.0 отдельного тега/релиза не получает** — не была опубликована до этого батча, её
  содержимое целиком входит в релиз v1.7.0 (прецедент — v1.4.0 → v1.5.0, см. манифест v1.5.0 §6).
  История секции [1.6.0] ниже не тронута.
